SmartFan 的第一个正式版本：菜单栏可自定义、高温防护分级介入、后台服务由应用自己管理。基于 ThermalForge 上游 0.2.3，并合入 MacFanPro 0.2.3.20–0.2.3.54 的修复。

## 更新内容

### 新增

- **菜单栏可自定义**：图标配温度与转速的数字，或一条折线曲线（温度占上半、转速占下半，各自归一化）。度量（均温 / 体感）、单位、采样频率与时间窗口都可调，首选项里有实时预览。
- **首选项窗口**取代原下拉菜单：左键点图标打开，分风扇 / 通用 / 菜单栏 / 传感器 / 关于五页；右键仍是模式与退出的快捷菜单。
- **高温防护**：温度持续偏高时分两步提高转速（90 °C 持续 10 秒 → 半速；半速下 95 °C 持续 30 秒 → 满速），降温后按同样的分档退回。两个开关分别控制是否启用、以及是否在「默认」模式下也生效（默认关）。
- **传感器页**：列出本机所有被读取的传感器键、数值，以及被忽略的键与原因——用于核对某个读数的来源。
- **后台服务由应用自管理**：安装、更新、重启都在应用内完成，只需一次管理员授权，日常不再需要密码或终端命令。
- **电源与固定速率**：固定速率用滑块指定转速，范围取自硬件本身。

### 修复

- **菜单栏每秒重绘约 5000 次**：给状态项图标赋值会让 AppKit 重新解析其外观，而外观变化的观察者又触发重绘，形成自激循环。实测空闲占用约 90% 单核，修复后为 0.5%。现在只在明暗结论真正改变时才重绘。
- **守护进程启动与停止时释放风扇**：新守护进程启动时「不持有任何东西」，上一个进程（被杀、崩溃，或没有守护进程时被 root 直接写入）留下的手动转速会一直留在 SMC 上；现在启动时会归位自动控制，收到 SIGTERM 时也会释放自己持有的风扇。
- **守护进程的 socket 增加对端认证**：除文件权限外，连接时读取对端的 uid/gid，只放行 root 与属主，读不到凭据一律拒绝。
- **高温防护不再卡在半速**：防护此前按芯片热点键的最大值判断，而该读数长期停在触发线附近——既升不到满速，也等不到解除。现在按真实 CPU 核心与 GPU 判断，并让停止线低于触发线 5 °C。
- **面板 CPU 行与菜单栏数字不一致**：前者曾把同组内非核心的键算作 CPU 温度，两者最多相差约 10 °C。

### 改进

- **模式切换立即生效**：不再等待 4–8 秒的持续窗口，转速从风扇当前速度接着爬升，并设置了 10 秒冷却（「默认」不受限，它是噪音时的退路）。
- **曲线样式合并**：温度曲线 / 转速曲线 / 双曲线三选一改为「曲线」一种，由「显示温度」「显示转速」决定画哪几条。
- **说明文字改为白话**，读数行加 ⓘ 说明取值来源；单位、度量、采样频率等只在相关读数开启时才生效。
- 配套的新图标与品牌资源（`assets/logo/`：macOS/iOS 图标集、网站图标、矢量 logo）。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [SmartFan-1.0.0-macos-arm64.tar.gz](https://github.com/witt-bit/smart-fan/releases/download/v1.0.0/SmartFan-1.0.0-macos-arm64.tar.gz) | 完整应用，解压后即可使用，无需 Xcode |
| [SHA256SUMS](https://github.com/witt-bit/smart-fan/releases/download/v1.0.0/SHA256SUMS) | 下载完整性校验 |

解压后把 `SmartFan.app` 拖入「应用程序」，打开后它会请求一次管理员授权来安装后台服务。

也可以[从源码构建](https://github.com/witt-bit/smart-fan#安装)；Homebrew cask 尚在准备中。

## 升级说明

这是第一个版本，没有需要迁移的旧版本。首次运行时应用会请求一次管理员授权来安装后台服务，之后不再需要密码。

如果此前用过上游或其他版本，两者使用不同的应用标识与数据目录，可以并存，但同一时间只建议运行一个风扇控制程序。

## 验证与限制

- **自动化验证**：241 项单元测试在 Debug 与 Release 下均通过，另含断连客户端回归与打包资源校验；见 [CI 工作流](https://github.com/witt-bit/smart-fan/actions/workflows/ci.yml)。
- **本机验证**：在 Mac16,1（Apple M4、单风扇）上验证了安装与卸载、菜单栏图标（Dock / Finder / Launchpad）、首选项各页、传感器页，以及空闲占用（修复后 0.5% 单核）。
- **未覆盖**：其他机型与 macOS 版本、M5 及更新的芯片、无风扇机型；高温防护的阶梯与守护进程的风扇释放在真机上的表现仍待更多验证。
- **签名与公证**：当前产物为 ad-hoc 签名，**未经 Apple 公证**；首次打开可能出现系统提示，处理方式见[常见问题](https://github.com/witt-bit/smart-fan#常见问题)。
- **验证记录**：[菜单栏显示与首选项验证](https://github.com/witt-bit/smart-fan/blob/main/docs/menu-bar-display-validation.md)、[传感器校准记录](https://github.com/witt-bit/smart-fan/blob/main/docs/thermal-sensor-calibration-20260924.md)。
